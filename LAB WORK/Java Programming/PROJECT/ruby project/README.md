MusicPlaylistMajor - Eclipse Project (Ready)

How to use:
1. Import this folder into Eclipse: File -> Import -> Existing Projects into Workspace.
2. Add MySQL connector JAR to /lib and then to project's Build Path.
3. Edit DB credentials in src/com/music/util/DB.java (USER and PASS).
4. Run SQL script sql/create_schema.sql in MySQL Workbench.
5. Right-click com.music.app.MusicAppAuth -> Run As -> Java Application.

Note: Replace 'your_mysql_password_here' with your MySQL password in DB.java.
